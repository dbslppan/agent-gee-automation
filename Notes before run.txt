Catatan penting sebelum run:
Periode default di script adalah Juni–September 2024 (musim kemarau — cloud cover rendah, ideal untuk Jawa Timur). Kalau mau periode lain, ubah START_DATE dan END_DATE di bagian CONFIG. Untuk AOI blok kebun yang lebih presisi, ganti AOI dengan shapefile yang di-upload ke GEE Assets.
Untuk automasi Python mingguan, edit satu baris di gee_vi_export_madiun_auto.py:
python
GEE_PROJECT = 'your-gee-project-id'  # ganti dengan project ID GEE kamu

2. Label dan RF
Satu hal yang perlu diubah sebelum run:
python
"vi_tiff_path": "./GEE_LPP_MADIUN/S2_VI_Madiun_VI_Median.tif"
Arahkan ke path lokal dimana file GeoTIFF dari GEE sudah di-download dari Drive.
Yang dihasilkan setelah run berhasil — semua masuk folder model_output/:
model.pkl adalah model siap pakai untuk agent mingguan. pseudo_label_map.tif bisa dibuka di QGIS untuk validasi visual apakah label rule-based masuk akal secara spasial sebelum dipercaya. confusion_matrix.png dan feature_importance.png adalah laporan evaluasi. training_dataset.csv menyimpan semua piksel sampel untuk audit atau retrain.

Tentang threshold yang dipakai:
Nilai threshold sudah disesuaikan untuk kelapa sawit di iklim Jawa Timur musim kemarau. Yang perlu diperhatikan: RVI untuk sawit biasanya tinggi (kanopi tebal, NIR tinggi), sehingga batas RVI > 3.8 untuk kelas Sehat lebih konservatif dibanding tanaman semusim. Kalau setelah lihat pseudo_label_map.tif di QGIS ternyata terlalu banyak piksel Kritis atau terlalu sedikit Sehat, threshold bisa di-adjust di bagian THRESHOLDS sebelum retrain.
